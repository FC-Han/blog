- 现象：用户早上看到关于页显示代码，以为部署失败。

## 诊断结论
- **线上关于页完全正常**：grep 检查 `&lt;script|withBase|script setup` 全部为 0（零代码泄漏）；头像 `<img class="about-avatar" src="/blog/tx.jpg">` 正确；头像图片 HTTP 200；结构（about-hero/about-grid/about-card/about-actions）完整。
- 用户看到的"代码"= **浏览器缓存了旧版本**（GitHub Pages CDN 或浏览器本地缓存），非线上问题。
- 尝试过 markdown 图片 `![头像](/tx.jpg)` 方案 → VitePress 把 md 当 Vue SFC 编译，HTML 块内 markdown 图片导致 "Element is missing end tag" 构建失败 → 放弃，保留 `<script setup>` + `withBase('/tx.jpg')`（VitePress 官方支持，构建产物零泄漏）。

## 关键结论（复用）
- **VitePress md 里引用 public 资源**：markdown 内联 HTML 的 `<img src="/tx.jpg">` 构建能过但线上 404（缺 base）；写 `/blog/tx.jpg` 构建报 resolve 错；**正确做法是 `<script setup> import { withBase } from 'vitepress' </script>` + `:src="withBase('/tx.jpg')"`**，构建产物自动带 /blog 前缀。
- md 里 HTML 块内嵌 markdown 图片语法（空行包裹）会触发 Vue SFC 编译错误，不可用。
- 用户反馈页面"有代码/没内容"时，先 curl 线上 HTML grep 特征串确认，多数是浏览器缓存（让用户 Ctrl+F5）。

## 上午补充：真正的根因找到了！（重要）
- 用户坚持说关于页有代码 → **不是缓存，是真的泄漏**！抓线上 HTML 发现 `&lt;div` 3 处，python 定位：**关于页后半段（这个站点/最近在做/一句话卡片）被渲染成 `<pre><code>` 代码块**。
- **根因**：about.md 内联 HTML 卡片之间有空行 → markdown-it 遇到空行结束 HTML 块 → 后续 4 空格缩进内容被当作**缩进代码块**显示！这是 markdown 解析规则，之前完全没意识到。

- ⚠️ **经验**：VitePress md 里写复杂 HTML 结构（卡片网格等），**一律用 Vue 组件**，不要用 md 内联 HTML + 空行分隔（必踩代码块坑）。md 里只能写单行组件标签。
