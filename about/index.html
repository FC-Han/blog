🙋 关于我

你好，我是成。平时喜欢折腾各种小工具，把生活里零碎的想法写成文字留下来。这个博客就是我的一个小角落——技术笔记和生活碎片都在这里。

🛠️ 这个站点

  • 基于 VitePress 构建，原生支持 Markdown 与代码高亮。
  • 部署在 GitHub Pages，源码与构建产物分离（main / gh-pages）。
  • 文章、标签、日记一应俱全，写新内容只需丢一个 .md 文件。
